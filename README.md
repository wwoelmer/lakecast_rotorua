# lakecast_rotorua

This is a working repository for data storage and producing forecasts related to the MBIE-funded SmartIdeas project titled LakeCast: Enhancing lake ecosystem management with multisource integrated data and ecological forecasts.

Data are automatically downloaded daily at 6AM NZT from the high-frequency buoy located at the lake center, as well as any new data from 10 nearshore sites along the shoreline of Lake Rotorua. Sampling at these 10 sites is led by Te Arawa Lakes Trust and occurs 3x/week. Data from the Bay of Plenty Regional Council's Cyanobacterial Monitoring program which occurs weekly during summer are added manually as data become available.
